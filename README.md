ava-приложение для управления списком машин. Программа умеет загружать данные из файлов (.txt, .csv, .json), принимать их вручную, а также фильтровать, сортировать и удалять записи.

Для запуска нужно:
1. JDK 17 или новее;
2. Maven;

Как запустить проект:
1. Откройте папку проекта в IDE и выберите pom.xml как проект;
2. Maven должен подтянуть зависимости;
3. Найдите класс Main и запустите метод main;

Структура проекта:

pom.xml
src/main/java/
    Main.java                    — точка входа
    model/Car.java               — модель автомобиля + валидация полей
    collection/CarArrayList.java — самописная коллекция (своя реализация ArrayList)
    loader/CarFileLoader.java    — парсинг .txt и .csv
    loader/CarJsonLoader.java    — парсинг .json
    service/CarProcessor.java    — фильтры, сортировки и Stream API
    ui/Menu.java                 — консольное меню
src/main/resources/data/         — папка с тестовыми файлами

Файлы с данными:

- cars.json — 5 валидных записей;
- cars.txt — 5 нормальных строк + 1 заведомо битая для теста;
- test_data.csv — 5 машин и строка с заголовками;
- cars_bad.json — «грязные» данные для теста валидатора;
Программа проверяет, чтобы марка, модель и цвет не были пустыми, год находился в диапазоне от 1885 до следующего года, а мощность была строго больше нуля.

Сценарий использования:

1. Запустите программу, перед собой увидите консольное меню;
2. При нажатии на "2" (Загрузить из файла) вбиваете путь, например: src/main/resources/data/cars.json и программа напишет в ответ: "Загружено автомобилей: 5";
3. Жмите 6, чтобы увидеть общий список авто с нумерацией;
4. Если хотите добавить свое авто - нажмите "1" и впишите строку вида: Авто;Мадель;Год;Мощность;Цвет
5. При нажатии на "3" можно увидеть меню взаимодействия со списком, где можно отфильтровать или отсортировать автомобили по году или мощности;
6. Пункт 5 покажет всю информацию по машине, по номеру из списка;
7. Пункт 4 удалит автомобиль из списка;
8. Пункт 0 завершает работу программы.
